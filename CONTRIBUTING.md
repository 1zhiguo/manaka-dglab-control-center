# Contributing

Bug reports and focused pull requests are welcome.

- Do not include the game, generated game assemblies, saves, paid files, or third-party Mods.
- Do not include access tokens, local IP addresses, personal paths, or device identifiers in logs.
- Keep the hard safety limit authoritative over every waveform and event path.
- Add or update tests for changes to intensity mapping, pause behavior, Socket handling, Mod installation, and file operations.
- Run the non-network test suite before submitting. The local Socket integration test requires permission to bind a loopback port and may be unavailable in restricted environments.
