OPTIONAL: Custom Missions 2 phone settings page
可选：Custom Missions 2 手机设置页面

This DLL is NOT the core plugin and cannot run by itself.
此 DLL 不是核心插件，不能单独运行。

First install the top-level BepInEx folder and verify this file exists:
请先安装压缩包最外层的 BepInEx 文件夹，并确认以下文件存在：

BepInEx\plugins\ManakaNpcVoices\ManakaNpcVoices.dll

Only when Custom Missions 2 is already installed, copy
ManakaNpcVoices.CustomMissions2.dll into:
仅当游戏已经安装 Custom Missions 2 时，再将
ManakaNpcVoices.CustomMissions2.dll 复制到：

BepInEx\plugins\ManakaNpcVoices

Without Custom Missions 2, leave this optional DLL uninstalled. The core NPC
reactions, subtitles, and local audio still work normally.
未安装 Custom Missions 2 时请不要复制此可选 DLL；核心 NPC 语气、字幕与本地音频仍可正常使用。
