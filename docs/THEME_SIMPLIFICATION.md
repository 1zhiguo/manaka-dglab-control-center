# 直接切换主题（2026-10-26）

按最终交互要求，顶部按钮直接在日间／夜间主题之间切换；按钮文字表示点击后的目标主题，并随软件语言更新。不再打开外观弹窗，也没有单独的动画选项。

移除 `reducedMotion` 偏好接口与预览开关。已有配置中的 `reduced_motion` 字段不再读取，也不主动删除其他用户配置。预览维持自适应速度，可见时运行、隐藏页面或窗口时暂停；设备播放速度不变。

验证使用隔离的临时配置与离线演示：

- 中文浅色、英文深色各 16 项弹窗和偏好交互通过，包括鼠标点击、Space 切换、仅持久化 `theme` 字段和不存在外观弹窗。
- 9 项预览检查通过，包含预先保存 `reduced_motion=true` 时仍正常动画、反复切换主题不影响预览、隐藏停表。
- 6 项文案／波形兼容性检查和 192 项单元测试通过。

这组累计功能最初基于上游 `cde3df6`（v1.0.5 后的 main），草稿 PR 提交时尚未适配 v1.1.0。后续按用户要求在本地合并 `ca3c512`，集成 V4/Opossum/HUD；保持未提交、未推送，详见 [本地合并验收](V110_LOCAL_VALIDATION.md)。
