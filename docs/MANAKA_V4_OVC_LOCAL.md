# Manaka V4 / 负鼠本地预览（2026-10-24）

以下功能已纳入 v1.1.0 构建，更新说明见 [RELEASE_v1.1.0.md](RELEASE_v1.1.0.md)。1.0.5 及以前的 ZIP/EXE 不包含这些改动。

## 本次范围

- 界面按用户提供的游戏封面调整为紫灰底色、银白文字、玫紫强调色；支持原有中英切换与日夜主题。
- 删除原 A/B 波形监视页，以负鼠工作台替代，仪表盘与波形工作台中的实时预览保留。
- 波形／负鼠工作台、Mod 工具、NPC 语音之间添加侧栏分隔线。
- 保留 Manaka 原 V3 传输、游戏检测、NPC 插件和电刺激映射；新增 V4 共享 Hub，郊狼与负鼠各自独立选择、启停和授权。
- 负鼠支持直接同步振动器，以及 A/B 独立的同步、固定、随机波形池、动作映射、关闭。不搬运 Ricca 的剧情、受击、HP、音频或死亡策略。

## 实机步骤（需要用户自行验证）

1. 在「设备与游戏」右上二维码上方直接选择 V3/V4。V3 默认使用 9999；负鼠使用 DG-LAB 4 App / V4 的 9998。
2. V3 按单设备布局展示游戏与扫码卡片，下方直接显示四步连接教程；不显示郊狼/负鼠双设备选择卡片或负鼠额外二维码。扫码卡片提供暂停/继续输出。切换回 V3 时会停用负鼠，避免隐藏设备继续输出。双设备管理在 V4 页面进行。
3. 郊狼选 V4 时，上方二维码同时用于 V4 郊狼和负鼠。发现新的受支持设备槽位时即自动选中，不要求设备状态已经就绪；发现新的蓝牙连接时也可选中。保留已有选择，手动取消后不会在普通状态更新中抢回。手机已连不等于蓝牙或配件已就绪。
4. V4 设备选中后会先确认归零，不自动输出。每台设备需分别手动启用。硬件就绪后即可启用，无需先启动或进入游戏；没有新鲜游戏数据时显示「已启用 · 等待游戏数据 · 输出为 0」。
5. 在负鼠工作台设置低档、高档、硬上限与 A/B 配件。初始低 10 / 高 30，上限 30，默认只用 A 配件；中档 20 为扩展 Mod 预留。0–200，10 步进；发送端会进一步按 App 上限向下取整，不能向上舍入。
6. 进入可操作场景，切换游戏振动器：关闭=0，低/高=对应映射。随机档由遥测在主线程读取 `CommonVibratorController.Leader.currentMode` 的实际档位，跟随游戏自身切换，不提供单独的 Random 强度。旧插件若只报告 Random，则联动保持 0 并提示更新遥测；不会伪造一个随机档输出。
7. 游戏暂停、菜单、失败和无场景时负鼠为 0。负鼠不继承电刺激的失败/高潮惩罚。游戏启动前的手动启用只进入待机，不向传输层授权波形输出；首个新鲜游戏包到来后才进入游戏联动。按用户确认的恢复方式，V4 游戏遥测或输出刷新超过 500 ms 时仍立即归零并撤销传输层输出，但保留用户启用状态进入待机；只有中断之后新收到、仍未过期的游戏包才能恢复联动，缓存的旧包不能恢复。设备断连、App 输出任务确认超时或其他输出错误仍停用并要求手动启用。手动暂停或全部停止会取消待机启用，之后启动游戏也不会自动启用。
8. 保存负鼠设置会停止该设备，需重新启用，不改变郊狼设置。顶栏「全部停止」覆盖两台设备；再次输出仍需逐台手动启用。

## 负鼠工作台

- V3 下整页显示「当前使用 V3，负鼠工作台不可用」，不显示可操作配置，提供「前往切换 V4」按钮跳转设备与游戏页。启用和保存接口也要求 V4；切到 V3 会关闭负鼠配置弹窗并保留草稿，不清空原有规则。
- 「直接同步游戏」用于快捷配置，Off=0，Low/High 使用各自档位值，Random 跟随游戏当前实际档位；Medium/Middle 为扩展 Mod 预留，原版不报告中档。
- 「A/B 独立配置」允许一边同步振动器，另一边播放固定或随机包络，也可以分别配置动作。动作列表支持搜索、规律/静态/交互分类、每行的大波形预览与下拉波形预览；未配置动作默认同步振动器，规则可明确选择同步、指定包络、随机池或关闭。
- 第二页采用与 Pulse 波形工作台一致的波形库、通道策略、A/B 预览布局。点击 A/B 通道卡片后，先选择「同步游戏振动器强度」或「自定义」；自定义包含动作分配、随机轮播、固定波形。切换分类保留既有规则和波形池，A/B 独立。配置先进入草稿，在主工作台保存后才应用。
- 随机池可点击卡片增删，A/B 有独立的轮换计时；切动作可切包络但不会修改电刺激策略。
- 内置恒定、呼吸、轻敲、渐强四个自行编写的振动包络。悬停仅视觉预览，不发送设备输出。
- 「新建波形」提供独立 16 点编辑窗，含撤销/重做、平滑、镜像；留空自动编号。已有郊狼自定义曲线可以共用包络形状，但频率不复用，统一重新编码为负鼠帧。内置官方电刺激原始数据不会直接发送给负鼠。
- 所有输出仍受负鼠硬上限、App 上限、配件/静音与授权限制。保存后保持停止，需手动重新启用；降低 UI 硬上限时同时收紧档位和动作强度。
- 每次保存显示带时间的成功状态与右下角提示；底部成功状态在 2.5 秒后清除。修改草稿立即显示「尚未保存」，不再由固定的「已保存」文字覆盖动态状态。

显示的「请求强度」不是硬件实测值；连接页单列设备 App reported 值、通道上限和配件/静音原因。

## 可配置原生 HUD

顶部 HUD 旁的齿轮打开设置。可选郊狼/负鼠、A/B、数字、状态与波形；大小 60–180%、背景不透明度 0–100%、七种预设/自定义位置（X/Y 滑块）。默认放在底部偏左，避让右下角游戏面板。

HUD 仍使用游戏原生 Unity Canvas，适配窗口、全屏和分辨率变化，不使用桌面置顶窗。显示约 30 FPS，历史波形每 100 ms 采样。四路最大显示内容在同一画布内，设置预览不触发设备，隐藏 HUD 不等于停止设备。

本次已构建遥测插件 `0.5.0`。新控制中心发送本机 UDP HUD V2（旧 V1 仍可被新插件解析）。要在游戏里看到新 HUD，需先关闭游戏，在新控制中心安装/修复运行环境，再启动游戏；游戏不能热替换已加载 DLL。未更新的游戏组件会在 HUD 设置页提示升级。

本次没有自动覆盖 C/D 盘游戏目录。保留旧 HUD 类作为源码参考，实际 PlayerUpdate 只调用新版 CustomHudCanvas，不会同时显示两个 HUD。

## 连接反馈与设置

「设备与游戏」四张卡片分别显示游戏遥测已连接、手机 App 已扫码、郊狼已启用、负鼠已启用的柔和发光边框。只开启服务器不会发光；设备选中但未授权不会显示为已启用。发光使用轻量边框动画，不启用模糊渲染或额外高频遥测。

游戏卡片另有独立的进程检测：每两秒在后台通过只读 Win32 进程快照检查 `SecretFlasherManaka.exe`。选定游戏目录时仅匹配该安装路径；未选目录时按精确进程名检测。游戏进程已启动但遥测尚未连接时显示玫色高光与等待提示，收到遥测后显示绿色高光；启动检测不等于插件已就绪，不会授权设备。退出和切换游戏目录会取消对应启动状态。演示模式不扫描真实进程。

启用按钮保留点击能力，条件不满足时在右下角说明未扫码、蓝牙断开、未插入配件、通道静音、App 上限为零、归零确认未完成或游戏遥测过期等原因。后端同样检查条件；暂停与停止不受启用条件限制。

2026-10-24 用户确认，App 已添加设备但手机尚未蓝牙连接硬件时，可同时上报 `props.connectState="connected"` 与 `slotState.hasDevice=false`。自动选择此前误用了输出就绪条件，导致列表里有设备却未选中；现已分离。此时仍禁止输出，界面准确提示「已发现设备，请先在手机 App 中连接设备蓝牙」，不再笼统称为状态冲突。新增 `socket.v4_discovery` 状态日志，选中前也可核对设备类型、hasDevice、connectState 和阻止原因；不记录设备名称、二维码或波形载荷。

HUD 开关与齿轮放在同一边框内。侧栏新增「设置」，放置中英语言、日夜主题、HUD 设置、新手教程和本地配置/波形目录入口；显示偏好不会启用设备。

遥测以后台 UDP 实际收包时刻判断新鲜度，避免 UI 排队的旧消息被误认为刚产生。`telemetry.receive_gap` 记录游戏收包间隔，`telemetry.ui_delay` 记录 UI 消息处理延迟；`socket.v4_route_state` 中 `producer-stale` 与 `response-timeout` 分开记录，前者带刷新间隔。诊断日志不记录游戏对白、完整遥测或波形载荷。

## 来源与边界

`python/manaka_devices/{dglab_bridge,dglab_v4,dglab_v4_hub,network,audit}.py` 基于作者提供的 Ricca 根目录 `src/ricca_dglab` 当前源码迁移，保留了归零屏障、短租期、通道隔离与旧响应防护。本地又增加了实际写入前的 generation/授权复检和 UI selection epoch 过滤。

协议核对入口：https://github.com/dungeonlab-open/dglab-kit/blob/main/README_CN.md

本次未复制 `ovc.ts` 官方 GPL 振动波形，也未更改项目许可证或既有第三方声明。负鼠四个内置包络单独定义在 `python/manaka_devices/ovc.py`。原有电刺激官方波形的来源与声明仍按 THIRD_PARTY_NOTICES.md 保留。

配置新增 `socket_protocol`、`ovc_profile` 与显示专用的 `hud_settings`。保存使用原配置的原子合并，不重写电刺激规则/波形库，配置损坏时拒绝覆盖。设备选择与输出授权不持久化。V4 日志位于应用数据目录 `ManakaDGLab/logs/devices.jsonl`，不记录整段 V4 波形载荷。
