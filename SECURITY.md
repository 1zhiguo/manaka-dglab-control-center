# Security and safety reports

Please do not publish device identifiers, IP addresses, private game paths, logs containing personal data, or proof-of-concept instructions that could cause unsafe device output.

For ordinary bugs, use GitHub Issues. For a security-sensitive report, contact the repository owner through the private contact method listed on the GitHub profile and include only the minimum information needed to reproduce the issue.

The software controls an electrical stimulation device. Any report involving unexpected intensity, failure to pause, failure to respect the safety limit, or output after disconnect should be treated as safety-critical.
