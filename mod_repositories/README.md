# Public Mod repository slots

The public build does not include the game. It supports one-stop import and management of third-party BepInEx plugins, CustomMission V1 JSON files, CustomMission V2 folders, and ZIP bundles.

Third-party files without explicit redistribution permission are not bundled. Use the application's Drop-in inbox to import copies obtained from authorized sources. After import, the manager stores content in its local repository and only syncs a Mod to the selected game when the user enables it.
